ML Model Idea for WeCode: Personalized Topic Suggestions

---

✨ Objective
Build an ML-based system to analyze user question submissions and recommend:
- Which topics to study next (weak areas)
- Which topics the user is strong in
- Personalized suggestions to improve DSA performance

---

✅ Data You Have
From each user, collect:
- `userId`
- `questionId`
- `topic`
- `submitted` (Yes/No)
- `difficulty`
- (Optional) time taken, number of attempts, etc.

---

⚡ ML Workflow
1. Collect Submission Data
Structure it like this:
{
  "userId": "123",
  "Array": { "attempted": 10, "submitted": 8 },
  "Graph": { "attempted": 5, "submitted": 2 },
  ...
}

2. Analysis / Rule-based Engine (Baseline)
- Calculate submission rate per topic
- If submission rate < 60%, suggest it as a weak topic

3. ML Model (Advanced)
- Clustering: Group users based on performance patterns
- Collaborative Filtering: Recommend questions based on similar users
- Topic Classifier: Predict user strength in a topic given past performance
- Reinforcement Learning: Suggest next topic/question to improve skill

---

🚀 Bonus Features / Tips
- NLP: Analyze question text to detect hidden concepts
- Dynamic Difficulty Adjustment: Adjust question difficulty based on user rating
- Peer Suggestion: Pair users with complementary strengths for group study or mock interviews
- Visualization: Use charts to show mastery levels by topic
- Gamify it: Add streaks, badges, levels based on ML insights

---

🔎 Future Enhancements
- Connect to GitHub/LeetCode for external data
- Auto-detect burnout / plateau phases
- Predict probability of user solving a question before starting it
